Getting reports

  1. Publish one DNS record for the domain your mail is signed with. Your DNS host adds it as a TXT record named _aprf._domainkey, with the value v=APRFv1; rua=mailto:reports@yourdomain.com, using an address you read.
  2. Send as usual. Comcast emails one report a day for each signing domain and DKIM selector that sent to its users, from aprf-noreply@alerts.xfinity.com, with subjects starting APRF:.
  3. Filter those emails into one folder. Drop the attachments here, the saved emails, or the whole folder exported as an mbox file.

Not sure your record is right? dns-audit.com checks it along with SPF, DKIM and DMARC.

Questions

What is APRF?

Aggregate Performance Reporting is a draft standard from the IETF's Mail Maintenance working group. A mailbox provider sends you a daily summary of how its users received mail signed with your domain: how much went to the inbox, how much it treated as unwanted, and how people reacted. Comcast sends reports today as a beta. Read the plain-language introduction.

Why are there no percentages?

Each count is a bucket ceiling, not an exact figure. Comcast's counts come in steps of 100, and 700 means up to 700. Placement counts mail received that day, while engagement counts actions taken that day on mail from any day. Dividing one by another gives a ratio nobody measured, so this page shows the counts and how they move.

What does unwanted mean?

Mail the provider put somewhere other than the inbox, usually the spam folder. Each provider decides what it counts. When a report's version number changes, the page says so, because the provider may have changed what a category means.

What is a change worth a look?

A day when unwanted mail or negative reactions at least doubled and grew by 200 or more, or when inbox mail fell by half and by 200 or more, compared with the report before. Smaller moves are within the rounding, so they are left out.

What do the warnings and skips mean?

Every report is checked against the draft, and every message names the section. A report the page cannot trust is skipped: not valid JSON, missing header fields, or not exactly one UTC day as section 5.1 requires. A report that departs from the draft in a smaller way is read with a warning, such as an attachment name that does not follow section 8. If the same provider sends the same day twice, the first copy is kept with a warning, because the draft has not decided which copy should win. Copy for a draft review copies the list as text.

What is a stream?

One provider, one signing domain, and one DKIM selector. Reports arrive one per stream per day, so a domain that signs with two selectors gets two streams.

Can I run this on my own computer?

Yes. The same reader is a free command line tool, and it gives the same results as this page.

pipx install aprf-reader
aprf-reader reports/ --html summary.html

The source for both is on GitHub, and the tool is on PyPI.
